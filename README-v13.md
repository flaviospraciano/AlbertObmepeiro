# Albert OBMEPeiro v13

Para atualizar, suba `index.html` e `sw.js` para o repositório, substituindo os arquivos atuais.

No Firebase (Firestore → Regras), cole o conteúdo de `firestore.rules` e clique em Publicar. Essa nova regra permite reativar o Maestro com o código 728497 numa conta recriada com o mesmo e-mail.

## O que mudou

- **Painel Maestro:** nova lista "Erros recentes", com o dia e o horário de cada questão errada.
- **Botão voltar do Android:** volta para a tela anterior (fecha o rascunho, as janelas, a aula e o jogo, e volta de aba). Na tela inicial, ele pergunta se você quer sair do aplicativo.
- **Cobrança e alertas de dia sem estudo:** só valem para os alunos, nunca para o Maestro.
- **Rascunho:** um botão ✏️ no topo de cada questão abre um quadro de desenho. Tem preto, azul, vermelho, borracha e limpar. O desenho fica salvo enquanto você está na mesma questão.
- **Zoom:** continua bloqueado.
